# Матовые поверхности и PgBouncer — QA 2026-11-10

Продолжение утверждённой оболочки и концепта settings-persons.png по просьбе
пользователя: единые матовые поверхности вместо выбивающихся стандартных серых
элементов. Нативные SwiftUI/AppKit, без веб-оболочки и без новых провайдеров.

отброшены и доказательством не считаются.

## Обнаруженные и исправленные расхождения

- Серое системное выделение категории настроек заменено собственным; сохранены
  выбор категории, фокус, клавиши ↑/↓ и accessibility identifiers.
- Сегменты выровнены влево и ограничены по высоте, включая узкий вариант со скроллом.
- Пустой service principal-item занимал место на toolbar в настройках почты и
  сокращал «Настройки» до «Нас…»: он теперь отсутствует, когда нет сервисных контролов.
- На снимке пользователя шапка недельного календаря занимала сотни пунктов.
  Причина — Color.clear с ограниченной шириной и неограниченной высотой в HStack.
  Шапка вынесена в CalendarDayHeaders с ограниченной высотой; полоса «весь день»
  получает свою высоту по содержимому. В том же синтетическом окне просмотрен
  исправленный снимок: дни и полоса «весь день» компактны, временная сетка сразу ниже.
- У степперов выровнены размеры «−/+»; у рабочих дней фиксирована ширина подписи
  и переключателя, чтобы включение времени не сдвигало их по горизонтали.

## Фактические сценарии

- Задачи: список и настройки, свой переключатель compact off→on, вкладка планера.
- Персоны: основная оболочка, настройки книг, вкладка OSINT, вложенная вкладка
  соединения; поля и матовая карточка просмотрены. Ни install, ни test connection,
  ни enrichment, ни системная книга не запускались.
- Почта: чтение синтетического письма, toolbar, настройки, вкладка шаблонов и
  уведомлений. Запрос разрешения, сохранение правил и отправка не выполнялись.
- Календарь: неделя до/после исправления, настройки, рабочий день Makosh,
  синтетический понедельник включён, время 09:00→09:30→09:00 через AX;
  предпросмотр и внешние записи не запускались.

- При проверке ИИ обнаружено переполнение карточки влево/вправо и разный
  старт строк: автоматический Form.columns был неверен для вложенных HStack/VStack.
  Он убран: общий контейнер сохраняет явную раскладку каждой сервисной строки.
  Значения в селекторах ограничены одной строкой. WorkspaceFormLayoutTests
  проверяет три составные строки с длинным названием на ширинах 640 и 1000:
  все строки внутри viewport, имеют одинаковые левый край и доступную ширину.
  Повторное выполнение — PASS. После исправления просмотрены нативные снимки
  таблицы ролей и редактора: общие края трёх колонок, одинаковая ширина селекторов
  с назначенным и неназначенным подключением, пять равных полей редактора с
  постоянными подписями. Редактор закрыт Escape без сохранения.

- Teams: встроенная страница уведомлений, выровненные переключатели, карточки
  разрешения и аккаунта просмотрены; запрос согласия и сохранение не выполнялись.
- Файлы: просмотрены таблица и настройки; исправлены сокращённая подпись
  сортировки и системная полоса пустых строк. Итоговая таблица просмотрена: подписи фильтров
  читаются, пустая область без серой зебры; кнопки источников имеют своё выделение.
  После отдельной правки фокуса клик «Все файлы» и ↓ выбрали «Почта», таблица
  сузилась до двух писем; AX подтвердил фокус и выбор. Попытка сужения таблицы
  через AX Increment разделителя не изменила ширину: узкий fallback шапки
  этим способом не проверен.

- WhatsApp: список/выбор синтетического чата, уведомления; узкая внутренняя
  колонка ломала «Конфиденциальность». Заменена общими горизонтальными вкладками;
  итоговый снимок проверен, переключение вкладки подтверждено AX. Ни звонки,
  ни разрешение macOS, ни изменения профиля/приватности не отправлялись.
- Телемост: основная оболочка и встроенная форма подключения просмотрены;
  OAuth, участие, создание и экспорт не запускались.
- Telegram: список, синтетическая переписка с вложением и досье, основные
  настройки и оформление просмотрены. Правила Enter остаются native radio.
- Задачи повторно: список, равные вертикали кода и заголовка, настройки;
  после обнаруженного сокращения почти всех подписей footer добавлен компактный
  вариант. Итоговый снимок: счётчики и команды читаются, полные статусы в help.
  Попытка выбора строки через AX-текст не дала изменения; повторный native
  walkthrough массового меню не подтверждён (dropdown navigation script прошёл).
- Календарь повторно: компактная неделя и развернутое расписание рабочего дня;
  подписи/переключатели выровнены, кнопки времени равны. На узких пересекающихся
  событиях обнаружен перенос цифр времени; подпись ограничена одной строкой.

Оставшиеся границы проверки: эта запись обновляется фактическими результатами.
Нативные DatePicker, radio options, контекстные и системные диалоги сохраняют
платформенную семантику; это не утверждение о замене каждого элемента macOS.
Reduce Transparency, все длинные/пустые/ошибочные состояния и все размеры окон
отдельно визуально пока не проверены.

## Автоматические ворота

- Прямой PostgreSQL: два lease-теста — exit 0.
- PgBouncer: те же два теста — exit 0; живой владелец удерживает lease через COMMIT,
  после retirement другой сеанс получает его, явное close идемпотентно,
  новое соединение не наследует application_name-маркер.
- Первый полный scripts/test.sh через PgBouncer — exit 0: 4015 XCTest passed,
  0 failed, 3 skipped; Rust 59/59. Пропуски: microphone-precondition Telegram,
  OSINTLiveCheck и OSINTLiveGraphProbe. Живой OSINT не разрешён и не запускался.
- Отдельно CalendarHeaderLayoutTests и WorkspaceNavigationTests — 5/5;
  два lease-теста в этом отдельном запуске skipped из-за отсутствующего env,
  их PASS установлен отдельными запусками с конфигурацией выше, а не этим фильтром.
- После календарной правки и финального выравнивания контролов полный прогон
  запущен повторно; окончательный результат — в development-status.md.

Повторный полный прогон после календарной правки прерван владельцем сессии
(SIGINT, exit 254), чтобы сразу исправить замеченное переполнение формы ИИ;
он не считается PASS. После окончательной нативной проверки будет новый полный прогон.

Итоговый полный `scripts/test.sh` (`.local/matte-tests-acceptance.log`) — exit 0:
сумма 14 итоговых XCTest suites — 4022 executed, 3 skipped, 0 failures;
Rust 59 passed, 0 failed. Три пропуска перечислены выше. Ранний подсчёт 4015/4017
по строкам `Test Case … passed` не является суммой итогов suites; для окончательного
прогона используется именно 4022 executed. Две новые геометрические проверки входят
в полный прогон. После него правки вкладок WhatsApp, фокуса и компактного footer
прошли отдельный debug build и шесть layout/navigation tests (exit 0).
