# Профиль Telegram и модальные окна: синтетический QA

Продолжение [обхода настроек](settings-layout-qa.md) в `ui-redesign`.
В каждом разделе использован его изолированный DEBUG-запуск и свои подставные
данные; рабочий бандл и настоящие аккаунты не открывались.

## Профиль в двух размерах

`--telegram-layout-synthetic-preview` теперь связывает существующий
аватарный адаптер и редактор с тестовым собственным профилем. Идентификатор
аватарного адаптера не меняет прежний идентификатор переписки и черновиков.
Кнопка «Использовать тестовую фотографию» генерирует изображение в памяти
и открывает штатный редактор кадрирования без системного выбора файла.

Обычный размер — 1200 × 854 pt. Для нового изолированного окна добавить
`--qa-narrow-window` к `--telegram-layout-synthetic-preview`: начальная
ширина 1000 pt, высота та же. macOS может восстановить ранее сохранённую
геометрию, поэтому для сравнения использован отдельный идентификатор QA-бандла.
Две попытки перетаскивания края через CUA ширину не изменили. Размеры
подтверждены на нативных снимках 2400 × 1708 и 2000 × 1708 px (2×).

- В широком окне все восемь вкладок в один ряд. В узком — в два ряда без
  срезанных подписей или горизонтальной полосы; «Приватность» открыта из
  второго ряда. Карточка профиля, фото, описание и кнопка выровнены сверху
  слева в обоих окнах.
- Редактор фото — 480 × 460 pt, заголовок и закрытие закреплены вверху.
  Проверены выбор тестовой фотографии, окно кадрирования 560 pt, поворот,
  подтверждение сохранения, отмена и подтверждение удаления. Удаление и
  сохранение не подтверждались. Escape в кадрировании возвращает к редактору
  без черновика; Escape в редакторе возвращает к профилю.
- Первый проход показал, что предпросмотр 144 pt прятал действия черновика.
  Теперь предпросмотр 64 pt и обе кнопки находятся в первой карточке.
  На снимке узкого окна обе кнопки видны сразу после отмены подтверждения.
  Подтверждения остаются нативными диалогами macOS.

## Обход модальных окон

| Раздел | Просмотрено в нативном QA |
| --- | --- |
| Telegram | Редактор фотографии, вложенное кадрирование, подтверждения сохранения и удаления |
| Почта | «Новое письмо» с тестовой подписью, меню двух шаблонов; в настройках открыт редактор длинного шаблона и видна одна строка правила |
| Teams | Два тестовых аккаунта и список чатов загрузились до показа; в беседе «Мария Тестовая» видны файлы, уведомления и закреплённое сохранение |
| WhatsApp | Настройки тестовой личной беседы: одинаковые отступы, сохранение видно без прокрутки |
| Файлы | Подключение Paperless: заголовок, постоянные подписи трёх полей и единая строка действий |
| Встречи | Добавление ссылки: общий фон и кнопки, сохранение пустой ссылки недоступно |
| Задачи | Новое подключение Jira: поля и степпер, Escape возвращает в настройки |
| ИИ | Новое подключение: постоянные подписи пяти полей, Escape возвращает в настройки |
| Календарь | Добавление CalDAV и подписки по ссылке; оба окна закрыты Escape |
| Персоны | Подключение книги CardDAV; окно закрыто Escape без данных и подключения |

Почта в новой `qa_mail_` схеме получает подпись, два шаблона и правило
с локальной меткой. Существующие схемы не переинициализируются. Заполненный
снимок обнаружил лишний зазор из-за фиксированной высоты списков. До четырёх
строк форма теперь использует естественную высоту; более длинный список
ограничен 160 pt и прокручивается. Проверены одна строка правила и два шаблона
после исправления. Край меню шаблонов за пределами почтового sheet не входит
в его снимок CUA; полная геометрия внешнего края не подтверждена.

Проверены перечисленные окна и переходы. Системный выбор личных файлов, входы,
подключения, отправки, сохранение изменений провайдеров и все ошибочные
состояния в этот проход не входили. Системные полосы прокрутки длинных форм
и системные подтверждения остаются нативными.
