# Block13: решения исполнителя

В хронологическом порядке; это решения, а не утверждение о live Telegram или физической приёмке.

1. **Использован существующий feature checkout вместо нового worktree.** Сохранены текущие сборочные и QA-фикстуры; нет параллельных изменений кода. Цена ошибки: Меньшая изоляция файлов; проверяются diff и состав исходников.

2. **Продолжен уже одобренный перенос без повторного согласования дизайна.** Прямая команда владельца разрешает реализацию; личные аккаунты отдельно не разрешены. Цена ошибки: Отдельные инженерные решения могут потребовать корректировки.

3. **Подготовка всегда компилирует текущий Python-адаптер без чтения старого bytecode.** Воспроизведена подмена старым кэшем при одинаковых размере и времени файла. Цена ошибки: Небольшое замедление импорта Python.

4. **Перед изменением заявки читается полный ограниченный список без поискового фильтра.** Поисковая страница не доказывает отсутствие участника; частичный результат не допускает запись. Цена ошибки: Дополнительные RPC; более 10000 строк или 30 секунд дают отказ.

5. **QA запускается единственным scoped open с явными synthetic/config параметрами.** Повторная активация создавала второй процесс без аргументов; он остановлен. Цена ошибки: Иногда требуется отдельно активировать окно.

6. **При индексации исходники замораживаются до завершения и freshness check.** Изменение файла во время refresh уже давало неверную свежесть; неиспользованный результат не считается доказательством. Цена ошибки: Дополнительное ожидание перед правкой.

7. **Одинаковый текст и права сохраняют authority открытого меню.** Безусловная инвалидизация на перерисовке отменяла выбранный Reply. Цена ошибки: Замыкания живут до семантического изменения контекста.

8. **После отказа frozen XERJ v9 создан отдельный v10.** Новые поля lock несовместимы со старой схемой; старый индекс сохранён. Цена ошибки: Время и диск на повторную локальную индексацию.

9. **P2P-off и прокси ограничиваются в реальном native ICE allocator.** Запрещены host/STUN/UDP relay обходы. Первоначальное предположение о готовом SOCKS5 в ReflectorPort оказалось неверным; решение дополнено пунктом16. Цена ошибки: Некоторые неподдерживаемые сочетания relay/proxy завершают звонок отказом.

10. **Перед native media выполняется однократный audio preflight.** Nil/ошибка устройства не должны включать upstream physical fallback; dummy используется только для безопасной уборки. Цена ошибки: Ошибка устройства завершает звонок; неподтверждённая остановка удерживает reservation.

11. **Native call/access-hash/reflector Int64 считаются непрозрачными значениями.** Референс отображает уникальные reflector IDs в ограниченный локальный индекс; идентичность peer проверяется отдельно. Цена ошибки: Допускаются нулевые opaque metadata, не используемые как локальная личность.

12. **Изменение видео асинхронно ждёт фактический camera ACK.** После await заново проверяются callID/account/context. Цена ошибки: Внутренние вызывающие стороны используют async; C ABI сохранён.

13. **Неожиданная ошибка native allocation после начала работы завершает процесс.** Нельзя вернуть ложный результат cleanup после частичной конструкции; handle создаётся до native work. Цена ошибки: При нехватке памяти процесс завершается; OOM-инъекция не выполнялась.

14. **Лицензии сохранены байт в байт.** Upstream пробелы и пустые строки не нормализуются, SHA совпадают. Цена ошибки: Безопасные whitespace-предупреждения для этих файлов; собственный diff проверяется отдельно.

15. **Единственный свежий reviewer использует текущую модель.** Явное правило владельца multimodel-off приоритетнее модельного override из author workflow. Цена ошибки: Ревью может быть слабее более мощной, но не разрешённой модели.

16. **Добавлен собственный bounded SOCKS5 CONNECT adapter для обеих TCP-фабрик.** В закреплённом OWT нет SOCKS5; формат RawTcpSocket и шифрование сохранены. Прямого fallback/UDP association/remote DNS нет. Цена ошибки: Неподдерживаемое рукопожатие безопасно завершает звонок; реальный удалённый прокси может иметь особенности.

17. **Физические микрофон/камера и device release не заявлены проверенными.** Разрешены injected native media и lifecycle-тесты; физическая приёмка требует отдельной авторизации. Цена ошибки: Особенности настоящего оборудования могут потребовать исправлений.

18. **Live Telegram операции и remote call interoperability не заявлены проверенными.** Реальные engine paths проверены исходниками, Postbox и synthetic/native тестами; личные аккаунты не использованы. Цена ошибки: Серверная совместимость может потребовать последующей разрешённой приёмки.

19. **Отложенные reviewer live SOCKS/crash проверки выполняет root локально.** Обе ошибки воспроизведены до исправления; socket fixtures и loopback TCP разрешены без аккаунтов. Цена ошибки: Локальные фикстуры не охватывают каждый внешний прокси.

20. **UI, подпись, CI и лицензии проверяются отдельными integration gates root.** Source reviewer не может подтвердить runtime; release/notarization не заявлены. Цена ошибки: Отдельная распространяемая сборка может требовать дополнительной release-проверки.

21. **После отказа frozen XERJ v11 создан отдельный v12.** Новые lock-поля требуют свежего dataset; prior indexes сохранены, новая свежесть проверена. Цена ошибки: Дополнительные локальные время и диск.

22. **Лимит холодной CI job увеличен с25 до40 минут.** PR CI исходного head прошёл; параллельный push runner потратил18m25s на сборку и был отменён по25-минутному лимиту во время тестов. Код приложения не меняется; новый head проверяется заново. Цена ошибки: неудачная job может занимать runner до40 минут.

Отложенных Minor по единственному свежему ревью нет. Два Important исправлены с воспроизведением RED→GREEN; окончательные результаты и merge записываются в development-status.
